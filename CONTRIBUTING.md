# Como contribuir

Obrigado pelo interesse! O projeto está no início e toda ajuda é bem-vinda.

## Formas de ajudar

- **Médicos e estudantes de medicina:** revisar explicações, apontar erros ou conteúdo desatualizado (abra uma issue com o modelo "Revisão de conteúdo").
- **Desenvolvedores:** escolher uma issue com o rótulo `good first issue`.
- **Qualquer pessoa:** melhorar a documentação, sugerir fontes abertas e públicas.

## Regras de conteúdo

1. Não envie provas ou questões protegidas por direitos autorais sem permissão clara de redistribuição.
2. Não envie dados de pacientes, nem casos reais identificáveis.
3. Toda afirmação clínica precisa de fonte (diretriz, documento oficial ou artigo) com data/versão.
4. Conteúdo gerado por IA deve ser marcado como tal e só vira `revisado` após revisão humana.

## Fluxo técnico

1. Faça um fork do repositório.
2. Crie um branch: `git checkout -b minha-contribuicao`.
3. Faça suas alterações e abra um Pull Request descrevendo o que mudou e por quê.

## Conduta

Seja respeitoso. Críticas devem ser sobre o conteúdo, não sobre pessoas.
